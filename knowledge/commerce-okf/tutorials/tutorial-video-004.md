# How do I create a single product with variants?

Start from Products → Create Product. Add the core product details, pricing and shipping information, and images. If the product has choices such as sizes, add an attribute and its values, then review the generated variants, their images, and stock before saving.

## বাংলা

### ভ্যারিয়েন্টসহ একটি single product তৈরি করব কীভাবে?

Products → Create Product থেকে নাম, category, SKU, initial stock, description, price, discount, weight, dimensions ও ছবি দিন। size-এর মতো variation থাকলে Add Attribute থেকে value যোগ করুন, তৈরি হওয়া প্রতিটি variant-এর ছবি ও stock যাচাই করে Save করুন।

Product availability: **live**.

## Steps

1. Open Products and click Create Product.
2. Enter the product name and category, base SKU, and initial stock.
3. Add the description and size chart when applicable.
4. Enter the price, any discount, base weight, and dimensions.
5. Upload product images from the Media Gallery.
6. For variations, click Add Attribute and enter values such as sizes.
7. Review each generated variant, including its image and stock quantity.
8. Save the completed product profile.
