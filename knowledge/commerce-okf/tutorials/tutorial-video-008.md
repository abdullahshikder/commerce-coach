# How do I bulk upload products from a CSV file?

Open Products → Import Products, choose CSV as the source, select the warehouse, and upload the file. Review the column mapping, correct any product information that needs attention, then run the import.

## বাংলা

### CSV দিয়ে একসাথে অনেক প্রোডাক্ট upload করব কীভাবে?

Products → Import Products খুলে source হিসেবে CSV এবং প্রয়োজনীয় warehouse নির্বাচন করুন। file upload করে সব column mapping যাচাই করুন, দরকার হলে product information ঠিক করুন, তারপর Import চাপুন।

Product availability: **live**.

## Steps

1. Open Products and click Import Products.
2. Choose CSV as the source and select the destination warehouse.
3. Click Next, upload the CSV file, and continue.
4. Review every mapped column before proceeding.
5. Correct any product information flagged for manual attention.
6. Click Import and confirm that the products appear in Commerce.
