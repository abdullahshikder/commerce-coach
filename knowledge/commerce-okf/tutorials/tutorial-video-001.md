# How do I publish products to Pathao Shop?

A Pathao Shop account is created with the Commerce account. Open Products, select one or more products, choose Publish on Pathao Shop, review or edit the preview, and publish. The same action is also available from the Pathao Shop section.

## বাংলা

### পাঠাও শপে প্রোডাক্ট পাবলিশ করব কীভাবে?

Commerce অ্যাকাউন্ট তৈরির সময় একটি Pathao Shop অ্যাকাউন্টও তৈরি হয়। Products থেকে এক বা একাধিক প্রোডাক্ট নির্বাচন করে Publish on Pathao Shop চাপুন, preview দেখে প্রয়োজন হলে তথ্য ঠিক করুন, তারপর Publish করুন। Pathao Shop সেকশন থেকেও একই কাজ করা যায়।

Product availability: **live**.

## Steps

1. Open Pathao Shop to review or edit the automatically created shop profile.
2. Open Products and select the products to publish; use select all when needed.
3. Click Publish on Pathao Shop.
4. Review the preview and edit any details that need correction.
5. Click Publish and confirm that the products are available in Pathao Shop.
