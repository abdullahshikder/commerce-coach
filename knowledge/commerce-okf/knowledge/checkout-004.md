# Can I customize the checkout link experience?

Yes. When generating a checkout link, merchants can set: custom message/note, pre-filled delivery address, expiration time (for limited-time offers), and payment method restrictions. Links can also be branded with the merchant's logo and colors.

Product availability: **live**.

## How it works

- Generate link → Advanced Options.
- Set custom message/note.
- Pre-fill delivery address.
- Set expiration time.
- Restrict payment methods.
- Brand with logo and colors.
