# How do I customize my online store's look?

Navigate to Online Store → Store Settings → Branding. Upload your logo (recommended: 200×50px SVG or PNG). Set primary and accent colors. Upload banner images (recommended: 1200×400px). Choose font pairing. Preview changes in real-time before publishing.

Product availability: **live**.

## How it works

- Go to Online Store → Store Settings → Branding.
- Upload logo (SVG/PNG, 200×50px recommended).
- Set primary color and accent color.
- Upload banner images (1200×400px recommended).
- Select from 4 font pairings.
- Live preview available before publishing.
