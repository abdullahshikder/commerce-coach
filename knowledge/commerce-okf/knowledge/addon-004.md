# Is there an API for developers?

The Product Memo confirms a Developer API inside Instant Delivery for system-to-system order handling. It provides Client ID, Client Secret, access-token generation, and webhook configuration; it does not list endpoints, rate limits, or broader Commerce APIs.

Product availability: **live**.

## How it works

- Open Instant Delivery.
- Choose Developer API.
- Generate credentials and an access token where needed.
- Set the Callback URL and Secret under Webhook Integration.
- Do not share Client Secret or access tokens with support.
