# Can I use Pathao Commerce on my phone?

Yes. The Pathao Commerce dashboard is fully responsive and works on mobile browsers. Key features like order management, inventory checks, and chat responses are optimized for mobile. A dedicated mobile app is coming soon.

Product availability: **live**.

## How it works

- Access via mobile browser at commerce.pathao.com.
- Responsive design adapts to screen size.
- Key features optimized for mobile.
- Mobile app coming soon.
