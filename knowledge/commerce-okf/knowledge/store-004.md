# Can I see analytics for my online store?

Yes. Online Store → Analytics shows: visitor count, page views, conversion rate, top products, traffic sources, and revenue over time. Data refreshes hourly. No additional tracking code is needed — analytics are built-in.

Product availability: **live**.

## How it works

- Go to Online Store → Analytics.
- Metrics: visitors, page views, conversion rate, revenue.
- Filters: date range, product, traffic source.
- Data refreshes hourly.
- No additional tracking code needed.
