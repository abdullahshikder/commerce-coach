# Can I add custom pages to my online store?

Yes. Go to Online Store → Pages. Create custom pages like About Us, Contact, FAQ, Shipping Policy, or Return Policy. Each page supports rich text formatting, images, and custom URLs. Pages appear in the store navigation menu.

Product availability: **live**.

## How it works

- Go to Online Store → Pages.
- Click "Add Page".
- Enter title, content (rich text editor), URL slug.
- Add images if needed.
- Page appears in store navigation.
