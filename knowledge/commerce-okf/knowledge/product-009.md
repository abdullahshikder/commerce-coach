# Can I duplicate a product?

Yes. On the Products page, click the three-dot menu on any product and select "Duplicate". A new product is created as a copy with the same details (name + "Copy", description, images, pricing). The duplicated product is in "Draft" status and can be edited before publishing.

Product availability: **live**.

## How it works

- Products page → three-dot menu → "Duplicate".
- New product created as copy.
- Name gets "Copy" suffix.
- Same details: description, images, pricing, variants.
- Created in "Draft" status.
