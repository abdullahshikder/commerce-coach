# What is the Connection Hub?

The Connection Hub (Add-ons page) is where merchants manage all third-party integrations. Available connections: Pathao Courier (auto-connected), Daraz Connect, Facebook Connect, WhatsApp Connect, Meta Commerce, and API access. Each connection has its own setup flow and settings.

Product availability: **live**.

## How it works

- Navigate to Add-ons in sidebar.
- View all available connections.
- Each connection shows status (Connected/Disconnected).
- Click to set up or manage.
- Connection details and settings per integration.
