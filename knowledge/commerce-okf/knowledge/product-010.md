# Can I set SEO details for my products?

Yes. When editing a product, expand the "SEO" section. Set: meta title, meta description, and URL slug. These affect how the product appears in search engine results. Defaults are auto-generated from the product title and description if not customized.

Product availability: **live**.

## How it works

- Product edit → expand "SEO" section.
- Set: meta title, meta description, URL slug.
- Defaults auto-generated if left empty.
- Affects search engine visibility.
