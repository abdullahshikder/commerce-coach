# Can I create an order manually for a customer?

Yes. Start a manual order from the order area, add the customer and delivery information, select products and quantities, review charges and payment details, then create the order.

## বাংলা

### কাস্টমারের জন্য ম্যানুয়ালি অর্ডার তৈরি করা যাবে?

হ্যাঁ। Order সেকশন থেকে manual order শুরু করে কাস্টমার ও ডেলিভারি তথ্য দিন, প্রোডাক্ট ও পরিমাণ নির্বাচন করুন, চার্জ ও পেমেন্ট তথ্য যাচাই করে অর্ডার তৈরি করুন।
