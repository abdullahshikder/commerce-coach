# Where can I configure the webhook?

The Callback URL and Secret can be configured from the Developer API section.

## বাংলা

### ওয়েবহুক (Webhook) কোথায় কনফিগার করব?

আপনার Callback URL এবং Secret কি টি Developer API সেকশন থেকে কনফিগার করতে পারবেন।
