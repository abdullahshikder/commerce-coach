# When should I use WhatsApp Manual Setup?

Use Manual Setup when your WhatsApp Business configuration requires credentials or identifiers to be entered directly instead of the guided Quick Connect flow. Follow every field shown in the setup screen and verify the connection before using it for customer chats.

## বাংলা

### WhatsApp Manual Setup কখন ব্যবহার করব?

guided Quick Connect-এর বদলে WhatsApp Business-এর credential বা identifier সরাসরি দিতে হলে Manual Setup ব্যবহার করুন। setup screen-এর প্রতিটি ঘর অনুসরণ করুন এবং কাস্টমার চ্যাটে ব্যবহারের আগে connection যাচাই করুন।
