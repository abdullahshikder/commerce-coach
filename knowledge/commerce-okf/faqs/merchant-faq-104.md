# Can I crop an image inside Pathao Commerce?

Yes. Open the image editing or crop action from the supported media workflow, adjust the crop area, preview the result, and save the edited image before using it.

## বাংলা

### পাঠাও কমার্সের ভেতরে ছবি crop করা যাবে?

হ্যাঁ। সমর্থিত media workflow থেকে image edit বা crop action খুলুন, crop area ঠিক করে preview দেখুন এবং ব্যবহারের আগে edited image সেভ করুন।
