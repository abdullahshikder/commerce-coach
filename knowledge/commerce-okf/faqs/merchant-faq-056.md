# Can I use an API for Instant Delivery?

Developer API references and webhook configuration are available for eligible technical merchants.

## বাংলা

### আমি কি ইনস্ট্যান্ট ডেলিভারির জন্য এপিআই (API) ব্যবহার করতে পারব?

হ্যাঁ। যোগ্য টেকনিক্যাল মার্চেন্টদের জন্য ডেভেলপার API রেফারেন্স এবং ওয়েবহুক (Webhook) কনফিগারেশনের সুবিধা রয়েছে।

Product availability: **limited**.
