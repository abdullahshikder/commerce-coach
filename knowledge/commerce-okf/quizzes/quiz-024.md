# A merchant connected their Facebook Page but is not receiving Messenger messages in the unified inbox. What should you check?

## Options

- Whether the Facebook Page connection is still active
- Whether the page admin has granted message permissions
- Whether the Facebook app is in Live mode (not Development)
- All of the above

## Correct answer

All of the above

## Explanation

Check: active connection status, page admin permissions for messaging, and Facebook app mode. All are required for message sync to work.
