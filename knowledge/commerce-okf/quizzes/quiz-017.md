# What feature allows merchants to create an order directly from a chat conversation?

## Options

- Chat Export
- Chat-to-Order Conversion
- Quick Reply
- Chat Archive

## Correct answer

Chat-to-Order Conversion

## Explanation

The Chat-to-Order feature lets merchants click "Create Order" in any chat, select products, and confirm delivery details from the conversation.
