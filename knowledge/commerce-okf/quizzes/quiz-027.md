# A merchant can connect a custom domain to their Pathao Online Store without any additional setup.

## Correct answer

False

## Explanation

Connecting a custom domain requires CNAME configuration pointing to Pathao. SSL is auto-provisioned, but DNS setup is required on the merchant's end.
