# What is the default URL format for a published Online Store?

## Options

- www.mystore.com
- {store-slug}.pathao.com
- {store-slug}.pathao.shop
- store.pathao.com/{store-slug}

## Correct answer

{store-slug}.pathao.shop

## Explanation

Published stores are assigned the URL {store-slug}.pathao.shop. Custom domains can be connected optionally.
